# Gym Management System - Frontend (GymPro UI)

This is the frontend user interface for the GymPro management system. It's built with React, Material-UI (MUI), and uses Axios for API communication.

## Features

- User Authentication (Login, Registration forms).
- Role-based views and navigation:
    - Public: Homepage, View Plans, View Facilities.
    - Member: Dashboard, Profile Management (view/edit), View Plans/Facilities.
    - Trainer: Dashboard, Trainer Profile Management (specializations, bio, availability).
    - Admin: Dashboard, User Management, Plan Management, Facility Management.
- Dynamic rendering of content based on user role and authentication state.
- Responsive design elements provided by Material-UI.

## Prerequisites

- Node.js (v14.x or later recommended - for `npm` and `npx`)
- npm (Node Package Manager)

## Setup and Installation

1.  **Clone the repository (or ensure you are in the `gym-management-app` root directory if generated by an agent).**

2.  **Navigate to the frontend directory:**
    ```bash
    cd frontend
    # Or from root: cd gym-management-app/gym-management-app/frontend
    ```

3.  **Install dependencies:**
    ```bash
    npm install
    ```

4.  **Environment Variables (Optional):**
    The frontend might use environment variables, typically prefixed with `REACT_APP_`. For example, to specify the backend API URL if it's not running on the default `http://localhost:5001`.
    Create a `.env` file in the `frontend` directory:
    ```env
    REACT_APP_API_URL=http://localhost:5001/api
    # Adjust if your backend runs on a different port or domain
    ```
    If this file is not present, the application will default to `http://localhost:5001/api` for backend calls.

## Running the Frontend Development Server

-   Start the React development server:
    ```bash
    npm start
    ```
    This will usually open the application in your default web browser at `http://localhost:3000`. The page will reload if you make edits.

## Building for Production

-   To create an optimized production build:
    ```bash
    npm run build
    ```
    This bundles the app into static files in the `build/` directory. These files are ready to be deployed to a static site hosting service or served by a backend.

## Key Technologies Used

-   React (v17+ or v18+)
-   React Router DOM (for client-side routing)
-   Material-UI (MUI v5 for UI components and styling)
-   Axios (for making HTTP requests to the backend API)
-   React Context API (for global state management, e.g., AuthContext)

## Project Structure (Key Directories within `src/`)

-   `components/`: Reusable UI components, often organized by feature or role.
    -   `auth/`: Login, Register components.
    -   `admin/`: Components specific to the admin dashboard (plans, facilities, users).
    -   `trainer/`: Components specific to the trainer dashboard.
    -   `user/`: Components for general user features (e.g., ProfilePage).
    -   `plans/`: Components related to viewing plans (public).
    -   `facilities/`: Components related to viewing facilities (public).
    -   `routing/`: Custom route components (PrivateRoute, AdminRoute, TrainerRoute).
-   `context/`: React Context providers (e.g., `AuthContext.js`).
-   `pages/`: (Implicitly, top-level components like `App.js` define pages, or some components in `components/` act as page containers).
-   `theme.js`: Custom Material-UI theme definition.
-   `App.js`: Main application component, sets up routing structure.
-   `index.js`: Entry point of the React application, renders `App` and sets up providers.
